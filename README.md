# wp-llm-search-bar
#WP-LLM Search Bar Plugin für WordPress 7+  Ein **Gutenberg-Block**, der ein Suchfeld bereitstellt und **mithilfe von KI (WordPress 7.0 Connectors)** passende Inhalte auf der Seite vorschlägt. Das Plugin nutzt **semantische Suche**, um auch komplexe Anfragen korrekt zu verarbeiten.
